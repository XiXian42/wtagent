How to use

Requires Node.js 20.x ≥20.17, 22.x ≥22.13, or ≥23.5, and Chrome/Chromium.

macOS · Linux · Windows. WSL2 + WSLg: preview support.

Full setup guide ↗
1

Install WTAgent

npm install -g wtagent
2

Open a test project and start

mkdir wtagent-demo
cd wtagent-demo
wtagent

A dedicated Chrome profile opens. Sign in with your own web AI account when prompted. ChatGPT is the default provider.

3

Type a task in the terminal

create /tmp/helloworld.c and run it.

Choose your web AIwtagent --model claude

Replace claude with: chatgpt · deepseek · gemini · grok · kimi · glm

Usage notes

Use your own account and follow your provider’s terms and limits. Browser changes or access restrictions can interrupt use; account safety is not guaranteed.

Files and commands run locally, but code and output returned to the chat are sent to your web AI provider. Do not share secrets or unauthorized data.

Local policy checks are not an operating-system sandbox. Review commands and changes, keep backups, and start with a disposable project.
